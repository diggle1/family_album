## In

- 本家成员打开时光线（孩子视图或全家视图）时，若有上次成功打开之后新入库的照片、日志或视频，内容区顶显示日签条「最近有新内容」。角上是有更新的记录日天数；没有上次查看记录，或记录晚于现在，则显示「近 7 天有新的」。
- 点开日签条，同区列出这些日子：大号日期、类型角标（图 / 日志 / 视频）和「共 n 条」。点某一天进入已有的 `/children/{id}/days/{date}`。某一天页能看到这一天还在的照片、日志和视频。内容都删掉之后，页上是「这一天还没有内容」，不白屏。
- 没有新内容时，日签条不进入页面，不留空框，也不弹窗。
- 页面已经画出之后，再推进该成员 × 这家的 `last_seen_at`。先看再记，避免这一趟把顶条吃掉。重复推进得到的时刻不会倒退。
- 管理员、可上传、只读都能看，也都能推进自己的那一行。只读去写媒资仍被拒绝。非成员的拒绝体与现网一致，不带 `code`，也不带家里的名字。

## 升级

```bash
docker compose stop
docker compose up -d --build
```

容器启动时 `scripts/migrate.py` 建 `timeline_last_seen`，然后打印 `timeline_last_seen ready`。表已经在时再跑一次，不改已经记下的时刻。

不使用 Docker 时拉代码后执行 `python scripts/migrate.py`，再重启进程。

## 回退

回退到 `v2026.10.25.3`。`timeline_last_seen` 留在库里，旧版本不读它。再升回本版后，已经记下的时刻还在。

```bash
docker compose stop
git checkout v2026.10.25.3
docker compose up -d --build
```

不要执行 `docker compose down -v`。不要删表，也不要清掉 `timeline_last_seen` 里的数据。那一步不可逆；若要彻底撤掉这张表，另走数据删除审批，先备份再手动处理。
