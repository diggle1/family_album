## 回退

这是空仓上的第一版，没有更早的产品 tag。空仓基线是 `main` 上的 `db09d34`：

`db09d345eb67b9885711f9c8bd3f033141e8bc40`（短号 `db09d34`）

只退代码不会清掉已经写入磁盘的库和照片。需要三步一起做：

```bash
# 1. 停掉 uvicorn
# 2. 代码回到空仓基线
git checkout db09d345eb67b9885711f9c8bd3f033141e8bc40

# 3. 数据：SQLite 与照片目录不会随 checkout 消失
rm -f data/app.db data/app.db-journal data/app.db-wal data/app.db-shm
rm -rf data/photos
mkdir -p data/photos
```

若只是想回到本版而不是退到空仓：

```bash
git checkout v2026.10.23.1
```

回退前建议先复制 `data/app.db` 和 `data/photos/`。
