## In

- 家长管理员和可上传的家人，在某一天页给至少一位在册孩子留一句纯文字。同一人同一天只有一句；再提交就是改这句。全家成员都能看，包括只读的长辈。
- 这一天没有句子时，暖纸签不进页面，不留空框，也不催更。有句子时，卡片排在这一天的日志、视频和照片下面。
- 时光线的日卡只在有句子时，底部多一行虚线小字，内容是这一天最早的那句。没有句子的日卡保持原样。
- 从孩子的某一天进去，写的时候先带着这个孩子，还可以再点兄弟姐妹。从全家某一天进去，不预先选中任何人，需要自己点至少一位。不能把已经选中的最后一位清掉。
- 只读家人看得到句子和「只读 · 只能看」，没有写的入口。直接调用写接口会被拒绝。不在这个家庭里的人，拒绝体与现网一致，不带 `code`，也不带句子正文。
- 家长管理员可以删任何一句，不能改别人的句子。可上传只能改、删自己的。删掉是软删除；同一天再写，会新起一行。
- 手机底栏和电脑顶栏是同一个写入口，不是新的底部标签，也没有右侧栏。桌面内容仍在中间一栏。没有推送。

## 数据库

新增两张表：`day_notes`、`day_note_children`。

`day_notes` 记下家庭、作者、日期、正文和删除时刻。未删除的句子，在同一家庭、同一作者、同一天上只有一行。`day_note_children` 记下这句写给哪些孩子，孩子编号不加外键，和日志、照片的关联一样。

升级前备份（路径以部署 `.env` 里的 `DATABASE_URL` 为准）：

```bash
docker compose exec web python -c "import sqlite3;s=sqlite3.connect('/data/app.db');d=sqlite3.connect('/data/app.db.bak-v2026.10.25.5');s.backup(d)"
```

## 升级

```bash
docker compose stop
docker compose up -d --build
```

不使用 Docker 时拉代码后执行 `python scripts/migrate.py`，再重启进程。
