  1. ① 准备机子

    准备一台能安装 Docker 的机器。

  2. ② 复制 .env 并写入密钥

    先复制示例，再写入高熵 SECRET_KEY。Phase A 自测可以临时打开测试码，生产必须关掉。不要把 ALLOW_INSECURE_DEFAULTS 或真实密钥写进镜像。

    cp .env.example .env
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'

    把上面命令的输出写进 .env 的 SECRET_KEY。自测时可临时设置 AUTH_TEST_CODE=000000，生产环境清空或不设置。

  3. ③ 拉起服务 
    docker compose up -d
  4. ④ 打开网页

    浏览器访问 http://<host>:8000。

  5. ⑤ 管理员登录

    用管理员账号登录。若开了临时测试码，先发送验证码，再输入 000000。

  6. ⑥ 上传一张孩子照

    上传成功后，用登录态打开 /media/…，应返回 200。图片经登录鉴权查看，没有公开直链。
