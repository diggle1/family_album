### 6.1 状态机（对齐 flow）

```

              ├─ 单张失败 fail_one（签上可感知 + 去看已放入的）

桌面同路径：desk_bar / desk_open / desk_bar_day / desk_progress / desk_day / desk_self
```

### 6.3 默认值与「上次挂的孩子」（写死）

- 日期默认今天（本地日历日，Asia/Shanghai 与现网 `today` 口径一致）。  
- 「上次挂的孩子」：本账号客户端偏好，键名建议 `fa.last_tagged_child.{user_id}`（`localStorage`）。成功放入至少一张孩子照片后，更新为本次锚点孩子（与 §5.4 锚点规则一致）。不写 cookie、不入库、不随请求外传。  
- 回退顺序（偏好缺失、或该 id 已不在本家孩子列表）：① 当前时光线正在看的那个孩子（若是单孩视图）；② 家中第一个孩子。从某孩子时光线 FAB 进来，**仍默认上次挂的孩子**（不是「当前正在看的孩子」），点芯片可改——与 cut「默认上次挂的孩子」一致。  
- 独孩家庭：无「再贴人」，芯片不写「· {孩子}」。  
- 家人路径不使用该偏好。

### 6.4 底签与上掀

- **形态：** 贴在当前页脚的暖纸底签（`--paper` `#FFFCF7`）。顶为重复径向撕边（高约 10px，径向圆在顶边外，暖纸从撕缝落下），决策条**不再叠齿孔、不画左 stub**。点主钮后同一条换成 `.1` 齐格签进度（进度签可保留齿孔）。  
- **默认条：** 左轻叉（aria-label「拿掉这些」，界面只出 ✕；放弃所选、收起底签，**不会放入**）+ 已选小缩略（最多出示 3 枚，约 18×18、圆角 3、纸边描边）+ 口语「n张」（无空格，如「5张」）+ 芯片「今天 · {孩子}」+ 右主钮「放入」。芯片与主钮必须分开。有超帽张时主钮不可用，条上出口语 `err_size`，不写 KB、不另开说明面板。有非图则跳过并出口语 `err_bad`，其余仍可放。  
- **上掀：** 点芯片才上掀**同一张纸**，不是新页。上排小节标题「哪一天」：今天 + 往回最多 2–3 个已过去的自然日芯片（文案 `{mo}月{d}日`，不写死稿中日期）+「选一天」。「选一天」打开**系统日期控件**，不另开整页日历。下排小节标题「再贴人」：纸上小脸（44×44、圆角 12、名在下方；选中 accent 描边 + 浅底光环 + 角勾）。可多挂，提交仍走现网 `child_ids`，规则与 `.1` 相同，只换外观。**不得使用黑底胶片条。** 独孩、家人路径不出这一排。上掀时轻叉与主钮仍留在底签上。  
- **家人：** 家人 tab 高亮，不叠在孩子时光线。芯片只写「今天」或所选日期（不拼「· 记在我名下」）；条上留一句青绿「记在我名下，不进孩子时光线」，须一眼看得见。主钮青绿「放入」（不用「放到我的相册」）。上掀只改日期，无小脸。  
- 宿主：复用并改写 `upload_day_slim.js`（拆出上传内核，确认 UI 改挂到时光线 / 家人页）。时光线 / 相册页需下发孩子列表 JSON 与 COPY，供底签使用。

关于「哪一天」：上掀小节标题用 final COPY「哪一天 / 再贴人」，这不是填表确认整屏。整屏标题「放到这一天」、已选一行 + 整条胶片贴布局不得再出现。

### 6.5 进行中 / 失败 / 成功（继承 `.1`，不重做样式）

点主钮后，底签换成已上线的一行暖纸进度签：「正在放入 i/n」+ **整票底边 3px accent 细线跟当前这张**（不是整批 i/n 比例）。仍停在原处。压缩等待时细线在 0，文案仍「正在放入 i/n」。禁止第二块面板、只转圈、右侧短棒、写出压缩率或 KB。串行、离页中止、迟到 201 忽略 UI 鬼影：全部沿用 `.1`。失败写在同一张签上（`fail_one` + `fail_go`）。成功落到当天齐格 + toast + 2px accent 细描边，不盖「刚放进」角标。

### 6.6 双端 / token
