## 主张：琥珀年签（FINAL）

- **有媒资**：时光线顶区一条**撕边琥珀年签单卡**——左侧**琥珀年号戳**（双线圆印 + 大年份如「2025」），嵌**缩略拼贴**（吸旧相框，一眼见有图），大字「去年今天」，类型角标带计数。
- **点卡** → 已有「某一天」页（去年同月日）；不新开详情模型 / Feed / Tab。
- **无媒资 / 2-29 无对应日**：整卡**完全不渲染**（不占位、不空壳、不弹窗）。
- **与「最近有更新」并存**：日签条在上、琥珀年签在下；间距清晰；禁止合成一条。
- **桌面 ≥1024**：仍在时光线**内容柱内**（max-width ~720），**不作**右侧独立栏。
- **与日签可感知差**：日签=撕边顶条可展开；年签=单卡+年号戳+缩略；**不作**木色相框主形态。

## 状态机（主路径 · 只读长辈）

```
打开本家时光线（Asia/Shanghai 今日）
  │
  ├─ 拉「最近有更新」？ → 有则渲染日签条（既有刀）     占顶
  │
  ├─ 匹配去年同月日媒资（只一年前）
  │     ├─ 有 → 渲染琥珀年签（在日签之下 / 或单独）   #s=tl_otd / tl_both
  │     │         └─ 点卡 → 既有某一天页（去年同月日） #s=day
  │     └─ 无 / 2-29 无对应日 → 年签不渲染             #s=tl_none
  │
  ▼
某一天页媒资已被删 → 现网空态，不白屏                 #s=day_empty
```

## 状态机（范围）

```
入口上下文？
  ├─ 全家入口 → 全家去年今天相关媒资（角标合计）
  └─ 孩子页   → 仅该孩子相关                         #s=child_filter
```
