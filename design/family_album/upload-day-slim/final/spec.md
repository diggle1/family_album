## 2. 组件 · 齐格签

| 组件 | 规则 |
|---|---|
| **进度签（主形态·传）** | 一行暖纸票：左小齿孔票根 + 口语「正在放入 2/5」+ **整票底边 3px accent 细线**。细线表示**当前这张**的进度（稿中约 62%，不是 2/5=40% 的整批比例）。文案已承担张数与序号。高 40。不是系统进度条、不是第二块卡片/面板、不是右侧短棒、不只转圈。不写压缩率、不写体积数字单位缩写、无画质/压缩开关。压缩默默做到可传体积（沿用现网日常上传单张帽，自 `.7` 起为 20 MiB）。 |
| **齐格（主形态·天页）** | 暖纸上的等大方邮票（虚线齿孔边）。手机 **3 列**，边距 12、纸内边 10、间距 **10**（不用相格纸 gutter 4 的密缝），单格边长 **≥108**（约 108.7）。桌面内容柱内 **5 列**，间距 12。1 张、2 张走**同一套齐格**（左起依次放，不拉成 4:3 英雄位、不对半切）。≥3 同样齐格。多了可下滑，**不靠 +N 藏图**。不做细密瀑布流。点开大图，左右滑看同天其余。 |
| **天页顶栏** | 日期**只出现一次**（顶栏标题「11月14日 周六」），副行带口语「共 N 张」（及孩子名+年龄，或家人相册名）。不要再在纸头重复一天标题。 |
| **加载** | 同一套齐格骨架，不只转圈。 |
| **时光线当天卡** | 沿用现网日卡结构：日期 + 周几 + 年龄胶囊 + 署名「妈妈传」。照片区最多一小排（约 4）缩略 + 口语「共 N 张」。点整卡进入某一天页。不在时光线铺开全部照片。不用 +N 遮住其中一枚缩略。**不另起日历票根**，免得和顶上的看谁签抢形。宽屏同样一小排，不因桌面变宽铺开。 |
| **确认步** | 选图后：已选小邮票一行（边 52）+ 日期芯片「今天 · 11月14日」+ 胶片贴挂谁。主钮「放进这一天」固定底部。步骤 ≤3：选图 → 确认 → 完成。无第二向导。手机一屏走完确认提交。日常上传默今天，可改；**不是**日堆签/旧库导入流。 |
| **家人「记在我名下」** | 无胶片贴；青绿说明「这些照片记在你名下，不会出现在孩子时光线。」；主钮「放到我的相册」。同一套一行进度签。完成后落到家人相册当天齐格。 |
| **成功去向** | 完成后落到**当天齐格**，刚放入的图可见：短提示「已放进今天」+ 新图 **2px accent 细描边**。不在每枚新格上盖「刚放进」角标。不丢进未知页。 |
| **失败** | 写在同一张进度签上：「4 张已放入，有 1 张没成功」，并提供「去看已放入的」。不假装成功。非图/损坏：跳过该张，确认步口语「有一张不是照片，已跳过。其余可以继续放。」超过单张帽：口语「有一张太大了，先拿掉再放」，不写 KB、不另开说明面板。 |
| **看谁签 / 胶片贴 / FAB** | 沿用定稿，本刀不改。只读无 FAB、无上传入口；可看当天卡与天页齐格。非成员拒绝句与现网一致，不露出家庭名。 |

## 4. 给 tech

1. **范围**：只收日常上传确认步 + 某一天页展示 + 时光线当天卡。不改旧库导入 / 日堆签，不把 EXIF 分堆流搬进日常上传。不改看谁签、权限三档、数据模型（不新表不新列），不改日志 / 一日一句 / 视频上传主路径。微信停。  
2. **步骤**：选图 → 确认（挂谁、哪天）→ 完成；≤3；无第二向导；无画质/压缩设置页或开关。默默压到可传体积，界面不提压缩。  
3. **进度签**：进行中只渲染一行暖纸票，文案「正在放入 i/n」。**底边细线表示当前这张的进度，不要做成已完成张数/总数的整批比例**（「正在放入 2/5」时细线不是 40%）。禁止只转圈、禁止第二块面板、禁止右侧另起短棒、禁止展示压缩率或体积数字单位缩写。  
4. **成功去向**：完成后进入该拍摄/挂载日的天页齐格，刚上传的图可见（短提示「已放进今天」+ 新图 2px accent 细描边）。不要在每格盖「刚放进」角标。不要丢到空白首页或未知页。家人路径落到个人相册对应那天。  
5. **天页齐格**：CSS Grid 等大正方形。手机 3 列，单格可点（边长建议 ≥108，间距 10，勿密到像商店瀑布）。桌面 5 列，间距 12。1、2、≥3 同一套模板，取消「1 张 4:3 / 2 张对半 / ≥3 左大右二 +N」。当天照片全部铺在格里，多了页面滚动。点格开大图，左右滑同一天。顶栏日期只出现一次，并带「共 N 张」。加载用同结构骨架。  
6. **时光线当天卡**：沿用现网日卡信息结构（日期+周几+年龄胶囊+署名），照片区最多一小排缩略（约 4 枚）+「共 N 张」；点卡进天页。不要在时光线铺开当天全部照片，不要用 +N 遮一枚缩略，不要改成日历票根以免和看谁签抢形。桌面同样一小排。  
7. **体积帽**：日常上传单张沿用现网（自 `.7` 起 20 MiB；基线 `.9` 仍用此帽）。超过口语拦住，不写 KB。损坏/非图跳过该张并口语可感知。单张失败其余已放入的要能看见，不假装成功。  
8. **权限**：admin / uploader 可传；只读无入口（无 FAB）可看齐格与当天卡；非成员拒绝码与现网一致，不露家庭名。  
9. **双端**：390 与 ≥1024 同路径、同规则、同文案。桌面内容柱 max-width 720 居中。  
10. **禁词**：见硬闸。本刀不出现微信小程序屏。
